# 3D Water-Immersion Ultrasonic Scanning System

I built a three-dimensional water-immersion ultrasonic scanning setup from scratch in the Laser Ultrasound Lab at Nanjing University. The system combines a mechanical scanning platform, an ultrasonic measurement chain, and instrument control. I then used a stepped reference block and a flat-bottom-hole reference block to check its basic thickness-measurement and defect-detection capabilities.

**Status:** Unpublished experimental work. This page reports a qualitative validation; quantitative results and figures have not yet been added.

## My contribution

- Built and integrated the mechanical, ultrasonic, and instrument-control parts of the system from the ground up.
- Carried out validation experiments on stepped and flat-bottom-hole reference blocks.
- Checked whether the setup could measure thickness and detect known artificial defects.

## System overview

| Subsystem | Function |
| --- | --- |
| Mechanical scanning | Positions the transducer relative to the specimen in three dimensions. |
| Ultrasonic measurement | Sends and receives ultrasound through the water-immersion path. |
| Instrument control | Coordinates instrument operation during scanning and data collection. |
